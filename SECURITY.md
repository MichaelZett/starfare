# Security policy

Please do not report security vulnerabilities as public issues.

Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/MichaelZett/starfare/security/advisories/new).
Describe the affected page or function, the steps to reproduce it and the
possible impact. Without a GitHub account, use the contact address in the
imprint of [starfare.zettsystems.de](https://starfare.zettsystems.de/imprint).

Only the version running at starfare.zettsystems.de (the latest release) is
supported. Do not test against other players' accounts or games, and do not
run load or denial-of-service tests against the server.
